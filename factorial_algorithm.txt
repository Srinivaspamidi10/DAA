=== Factorial Algorithm (Iterative & Recursive) ===
- Objective: Compute the factorial of an integer n using both Iterative and Recursive approaches.
- Algorithm / Pseudo-code:
  Algorithm FactorialIterative(n)
  1. result = 1
  2. For i = 1 to n do: result = result * i
  3. Return result

  Algorithm FactorialRecursive(n)
  1. If n == 0 or n == 1 then Return 1
  2. Else Return n * FactorialRecursive(n - 1)
- Complexity: Time: O(n) | Space: O(1) iterative, O(n) recursive stack
