Algorithm: Longest Common Subsequence (LCS)
Input: Two sequences X of length m, Y of length n
Output: Length of the LCS and the reconstructed LCS string

1. Create a 2D array dp of size (m + 1) x (n + 1), initialized with 0.

2. Populate the DP table:
   For i from 1 to m:
       For j from 1 to n:
           If X[i - 1] == Y[j - 1]:
               dp[i][j] = dp[i - 1][j - 1] + 1
           Else:
               dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

3. The length of the LCS is found at dp[m][n].

4. Reconstruct the LCS string via backtracking:
   Set i = m, j = n
   Initialize an empty list lcs_chars
   
   While i > 0 and j > 0:
       If X[i - 1] == Y[j - 1]:
           Append X[i - 1] to lcs_chars
           i = i - 1
           j = j - 1
       Else if dp[i - 1][j] > dp[i][j - 1]:
           i = i - 1
       Else:
           j = j - 1

5. Reverse lcs_chars and join elements to obtain the final LCS string.
