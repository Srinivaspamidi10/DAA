=== 0/1 Knapsack Problem (Dynamic Programming) ===
- Objective: Maximize the total value of items in a knapsack of limited capacity using Dynamic Programming.
- Algorithm / Pseudo-code:
  Algorithm Knapsack(weights, values, capacity)
  1. n = length(values)
  2. Create a 2D table dp[n + 1][capacity + 1] initialized to 0
  3. For i = 1 to n do:
     a. For w = 0 to capacity do:
        i. If weights[i - 1] <= w then dp[i][w] = max(values[i-1] + dp[i-1][w - weights[i-1]], dp[i-1][w])
        ii. Else dp[i][w] = dp[i-1][w]
  4. Return dp[n][capacity]
- Complexity: Time: O(n * capacity) | Space: O(n * capacity)
- Output:
Enter the number of items: 4
Enter value and weight of each item:
Value of item 1: 60, Weight of item 1: 10
Value of item 2: 100, Weight of item 2: 20
Value of item 3: 120, Weight of item 3: 30
Value of item 4: 40, Weight of item 4: 50
Enter the knapsack capacity: 60
Maximum Profit = 280
