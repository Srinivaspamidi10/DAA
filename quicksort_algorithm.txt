=== Quick Sort Algorithm ===
- Objective: Pick a pivot element and partition the array such that elements smaller than the pivot go to the left and larger elements go to the right, then recursively sort the partitions.
- Algorithm / Pseudo-code:
  Algorithm QuickSort(arr)
  1. If length(arr) <= 1 then Return arr
  2. Choose a pivot element
  3. Create sub-arrays (left < pivot, middle == pivot, right > pivot)
  4. Return QuickSort(left) + middle + QuickSort(right)
- Complexity: Time: O(n log n) average, O(n^2) worst | Space: O(log n)
- Output:
[7, 8, 1, 5, 9, 10]
